# Overview — The Hyphaeic Stack

> STATUS: POSITION

The full stack a free, persistent system requires, built from first principles.
Each component answers one question a system must answer for itself.

    FDRS                     representation / time / locality
      ↳ HyphaFabric          distributed state & computation
        ↳ Modulus            deterministic physical state
    STOK-CORE                state-time possibility / planning
      ↳ Abzu                 embodied agency & control
    HyphaKernel              the executor
    HyphOS                   the real-time bearer for bodies
    HyphaeicOS               the instance across a peer network

There are cross-connections; do not read this as a strict dependency tree.

- `TECHNOLOGY/Core` — FDRS, HyphaFabric, Modulus, STOK-CORE, Abzu, HyphaKernel, HyphOS
- `TECHNOLOGY/HyphaeicOS` — the OS-as-instance, Web peer, Hyphax peer
- `TECHNOLOGY/Live Applications` — HyphaChat, ChessBender, Magnon, SIGIL

Live demonstrations are properties, not folders: each entry carries its own
`STATE` (ACTIVE · LIVE · INTERACTIVE · SOURCE · PROTOTYPE · RESEARCH).
