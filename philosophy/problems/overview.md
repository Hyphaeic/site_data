# Overview — The Problem Beneath the Machines

> STATUS: POSITION

A humanoid's fingertip feels something. Its local controller responds. Vision
runs at another rate. The main processor is doing something else. A planning
model may be reasoning over seconds rather than microseconds. And yet the robot
must still behave as one robot.

This is the pattern beneath every system we work on: **local-to-global
coherence under bounded communication, on different clocks.** The rest of this
section names the fundamental problems and shows how each appears in real
application domains.

- Coordination
- Representation
- Control
- Time
- Planning
- Embodiment
- Alignment
- Applications across robotics / distributed systems / swarms / agents / edge / geometry & simulation / biology
