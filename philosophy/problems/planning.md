# Planning

> STATUS: OPEN PROBLEM

How does a system plan by what keeps it viable rather than by maximizing a proxy?

## The problem

An agent must choose under uncertainty, incomplete representation, and local
time. It needs to preserve future capacity without becoming unable to commit.

## Failure mode

Reward compresses purpose into a scalar. Maximising it can collapse the thing
the reward stood for. Maximising optionality alone can produce paralysis.

## Direction

State-Time Option Kernels represent what can be reached from here. They frame
planning as feasibility and viability, while generative commitment evaluates
which closed possibilities create richer viable futures.
