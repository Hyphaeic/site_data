# Representation

> STATUS: OPEN PROBLEM

The map is not the territory; every description is smaller than the world.

## The problem, physically
A system steered by a description of the good drifts from the good the moment the description and the world diverge — and they always diverge.

## The problem, formally
Radix-by-function numeric geometry means the resolution of a representation is a function of context, not a fixed grid.
