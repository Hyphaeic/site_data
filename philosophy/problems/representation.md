# Representation

> STATUS: OPEN PROBLEM

Every description is smaller than the world it helps describe.

## The question

How can a system act on reality when it can never represent reality completely?

## Failure mode

The standard response to a mismatch between model and world is to specify the
model more precisely. That creates a new boundary and reproduces the mismatch
there. When optimisation pressure is then applied to the representation, it can
destroy information and capabilities the representation omitted.

## Direction

FDRS makes the resolution of a representation context-dependent rather than
fixed. More generally, the programme treats a model as a local instrument for
action, not as a sovereign substitute for the world.
